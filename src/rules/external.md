# Description: Clean external text (no task IDs, step numbers, or unrelated tools) and two-step external writes
- **Clean external text & two-step external changes:** In commit messages, MR/PR descriptions, Slack, and status updates, describe changes in words **without internal task IDs** (e.g. `F1`, `T2`), **session/step numbers** (e.g. `s1/2`), **or local agent workflow tools unrelated to the repository**. Changes outside the repository (remote branches, MR descriptions, Slack) follow a two-step rule: first a read-only preview block saving what it replaces, then the write block after agreement.
