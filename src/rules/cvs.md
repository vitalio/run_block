# Description: CVS diff inspection (cvs -nq update, cvs diff -u), explicit file commits, and safety guards
- **CVS workflow & safety:** Inspect status without modifying the working tree via `cvs -nq update` and review full changes via `cvs diff -u`. Always pass explicit file paths to `cvs commit -m "..." file1 file2` rather than committing the whole tree blindly, so unrelated modified files are never committed by mistake. Without explicit user approval each time: **no `cvs update -C` (discarding local changes), no `cvs remove -f`, no deleting/moving tags (`cvs tag -d` / `-F`), and no `cvs admin` history modifications.**
